# Knowledge map: подбор линейного и вахтового персонала

База знаний о рабочих задачах: подбор, аналитика рынка труда, коммуникации с кандидатами и исследование заказчиков.

Это не подтверждённая база актуальных вакансий и не регламент компании. Здесь сохранены контекст задач, предпочтения и предложенные рабочие шаблоны. Перед применением условия и цифры необходимо проверять.

## Как использовать
1. Начать с карты знаний и выбрать направление.
2. Прочитать соответствующий раздел.
3. Взять шаблон и заполнить подтверждёнными данными.
4. Для работы с ИИ передать AI_INSTRUCTIONS.md и нужные разделы базы.

Файлы Markdown связаны относительными ссылками. Их можно добавить в существующий репозиторий со скиллом. Файл исходного скилла skill_recruitment_editor.txt следует сохранить рядом: этот набор дополняет, а не заменяет его.

## Публичность
В набор намеренно не включены реальные контакты кандидатов, внутренние ставки, клиентские договорённости и названия объектов из прошлых обсуждений. Не добавляйте такие сведения в публичный репозиторий без разрешения.
